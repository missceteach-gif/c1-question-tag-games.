# C1.2 Game Lab · Miss C

An interactive, mobile-first C1/C1.2 practice library for adult EOI learners, based on the thematic curriculum and teaching material from the linked class Drive folder.

## Student entry point

If this public repository is served via GitHub Pages from the default branch and root folder, open:

https://missceteach-gif.github.io/c1-question-tag-games./c1-library/

This is a new **subdirectory** in the existing public C1 question-tag repository. The original question-tag homepage remains unchanged.

## What is included

- **10 course units** (Relationships; Education; Work; Home; Nature; Environment; Shopping; News; Technology; Travel).
- **120 target words/collocations/idioms** with meanings and natural examples.
- **65 targeted grammar questions** with answer-specific explanations.
- **30 guided pair/group speaking scenarios** without writing, microphones or timers.
- **10 writing/mediation formats** with paragraph map, useful expressions, topic-specific mission, register checks, a draft box and word count.
- **12 homophone questions**, plus a 20-question mixed revision challenge.

## Games

1. **Word Hunt** — choose the C1 expression that matches the definition.
2. **Match Maker** — connect words and meanings; immediate feedback with retries.
3. **Grammar Escape** — choose the correct structure and read the grammatical reason.
4. **Speak & Swap** — show one guided pair speaking card at a time; reveal a sentence starter if needed.
5. **Memory Flip** — predict a word meaning and reveal it with an example.
6. **Homophone Showdown** — distinguish similar-sounding words in context.
7. **Revision Roulette** — a cross-unit mixed quiz.

## Teaching use

Open any unit from the homepage, or directly share a unit link with the suffix `#unit-3` (replace 3 with a unit number). All prompts are general-purpose: no student names or class lists are published. Speaking cards are suitable for adult pairs or small groups, with large mobile-friendly text.

The writing drafts remain only in browser page memory (no server-side saving, no AI grading). Students may copy them to their own editor.

## Editing the library

- `data.js`: editable unit vocabulary, grammar questions, speaking cards and writing genres.
- `app.js`: JavaScript game logic and student interface.
- `style.css`: visual design and responsive layout.
- `index.html`: public entry point.

No build system, account registration, external library or paid hosting dependency is required.

## Quality checks

Committed files were fetched back from GitHub; application JavaScript was syntax-checked and all 65 stored grammar answer indices were validated. Browser/device rendering and the public GitHub Pages deployment are separate checks and are not guaranteed merely by repository commits.

The study activities are newly authored exercises, not reproductions of copyrighted exam papers or student records.
